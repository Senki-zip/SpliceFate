## 2. CausalBridge 当前到底怎样工作

其基本路径是：

```text
TF RNA → 染色质 peak 状态 → 靶基因 RNA
   ↑                         │
   └──── 下游基因若为 TF，可继续传播 ─┘
```

1. 用 motif、cofactor 和家族证据确定 TF–peak 候选；用基因组位置和 Granger 筛选 peak–gene 候选。
2. 在 WT 聚合状态上拟合每条单输入响应曲线，再尝试少量 2/3 输入组。当前配置 TF→peak 使用 spline，peak→gene 使用小 NN；源码还支持 saturation。
3. 单输入组合权重由 WT 中相邻拟合响应的绝对变化计算、归一化并冻结。这个权重不是因果效应，也不是统一的贡献估计。
4. 组模型拟合完整目标输出，与单输入组合比较；需要通过复杂度惩罚、有效样本、共线性和查询几何支持检查。当前候选组选单输入得分最高的前 2/3 个输入，不是遍历所有组合。
5. 扰动时计算同一冻结函数的 `F(x_KO) - F(x_WT)`。组模型被选中时替换该次完整差分，不再叠加单输入差分。
6. 沿支持的 bin 路线传播，保留不支持/外推/失败原因；主配置以相同有效细胞集合的 WT/KO 均值汇总。

重要实现细节：

- TF→peak 是逐目标 bin 的局部 Pearson 支持测试，选择第一个通过的 lag；每条关系最终仍汇总支持行拟合一条曲线。并非每个 bin 单独拟合一套函数。
- peak→gene 常规 Granger 使用 lag=1。bin 滞后不是实际小时，更不是 RNA 分子的剪接加工顺序。
- 原配置 RNA 有 CP10k、log1p(CP10k)、再一次 log1p 的不同层级；不能按变量名误用单位。
- 原 NN/样条主要按全 WT 拟合和训练指标筛选，没有证明独立 KO 预测准确率。README 也明确 WT 映射不能独立建立干预因果性。

## 3. 对 SpliceFate 的对应关系

推荐以以下路径作为初版：

```text
细胞自身的 RBP 表达代理量 + 固定 WT 状态
                    ↓
     motif/CLIP 候选 + 互作/复合体候选路径
                    ↓
           剪接事件各分支的选择概率
                    ↓
       有完整分子结构支持的链/异构体组成
```

这里剪接事件是直接可观测的响应层，不必为了模仿 ATAC 人为增加一层“不可观测剪接体活性”。没有蛋白/占据信息时，该潜变量很容易与事件系数互相抵消，难以识别。

对应关系：TF–peak 候选 → RBP–event 候选；peak 状态 → event 分支选择；peak–gene 函数 → event 与链/异构体的结构约束。最后一项优先由已观测结构决定，不另拟合一个自由的 event→isoform 黑箱。

首版覆盖 L1 Δevent choice / ΔPSI 和 L2 Δsplice-chain / Δisoform usage；Δgene RNA 和 fate 后续再增加。

## 6. 先验候选路径：有 motif 和无 motif 因子怎样进入

### 直接候选

在与事件相关的外显子、上游/下游内含子、剪接位点窗口中提取：motif 类型及分数、相对位置、链方向、CLIP、来源、家族扩展标记。motif 定义窗口和坐标转换在训练前固定；不按 KO 结果挑窗口。

当前事件为 mm10，oRNAment 位点为 mm39。准备候选表时必须保留原事件 ID，逐窗口/区块转换并检查链方向、锚点顺序及剪接结构一致性；失败和多义映射单列，不能直接用稳定基因 ID 把不同版本坐标拼起来。CLIP 可使用原生 mm10 或经过验证的 mm39 记录，不能把两套坐标当成额外重复支持。跨外显子 motif 逐块求交，不用其外侧包围区间冒充完整结合覆盖。

### 间接候选

无 motif 的因子 r 若与伙伴 s 有蛋白互作或同复合体证据，而且 s 在事件 e 有位点证据，则建立：

`r — 伙伴/复合体 — s — 位点证据 — e`

该路径只作为 r 可能影响 e 的候选输入，标记 `indirect_partner_candidate` 或 `complex_mediated_candidate`。不生成 r 的虚构结合位点，不把 s 的 motif 改名给 r，也不认为 r KO 必须改变 s 的 RNA。

首版只使用可解释的一跳伙伴，保留直接物理、物理关联、未指定关联、同复合体、同源推断的差别。高连接度蛋白不能通过多跳扩散连到全部事件；没有事件锚点的蛋白，仅有 PPI 覆盖也不足以提供 event-specific 预测。

因此“353/406 有先验信息”不能当作“353 个可执行事件级 KO”。准备阶段还需统计因子×事件候选路径、实际计数覆盖和条件表达变异。

## 7. WT 条件响应模型

### 输入

令 `E_ir` 为固定原始全基因分母归一化得到的 RBP RNA 代理量，`x_ir=log1p(E_ir)`。它不是测量到的蛋白浓度或 RBP 活性。首版明确称作表达代理干预；若以后增加可识别活性估计，应单列模式，不任意同时拟合自由活性和自由效应系数。

`z_i` 是 WT 固定状态协变量：真实阶段、批次、少量稳定表达状态轴及必要的 QC 背景。计算状态轴时应检查 KO 靶因子及其程序是否主导该轴。模拟短期条件响应时状态保持 WT，不重新给 KO 细胞做 PCA/聚类。

### 事件计数

对事件 e，记第 k 个合法竞争分支的整数支持为 `C_iek`，`N_ie=sum_k C_iek`。

```text
N_ie = 0：该细胞在该事件无可判定观测，不记作排除分支，不填成 PSI=0。
N_ie > 0：使用各分支计数拟合选择概率，保留其分母。
```

二分支可用 beta-binomial，多分支使用 Dirichlet–multinomial：

`C_ie ~ DM(N_ie, κ_e · p_ie)`

`p_ie = softmax(η_ie)`

分支最后一类作为参考 logits，避免任意整体平移。低覆盖时离散度需共享收缩，不能为每事件自由估计不可辨识的 κ。

### 条件预测器

`η_iek = b_ek(z_i) + Σ_r f_rek(x_ir,z_i) + Σ_(r,s) h_rsek(x_ir,x_is,z_i)`

- `b` 是状态、批次背景；`f` 是候选因子的条件响应；`h` 是已有伙伴/复合体证据支持的少量协同项。
- 先拟合条件线性/低自由度样条作为主模型；饱和曲线、小 NN 为比较模型，首版无 Transformer。
- 多输入主效应在同一事件模型中联合估计，使用收缩处理共线性。单输入曲线用于诊断和基线，不分别解释全部输出后再相加。
- 样条和交互项中心化，交互中去除已能由主效应解释的部分，配合层级正则，防止同一路径被主效应、伙伴效应、模块效应重复计算。
- 状态依赖使用共享系数加低维状态偏离，不为每个阶段单独拟合所有 RBP。某阶段因子变化不足时，不能强行宣称该状态的特异效应。
- PPI 只约束候选和先验收缩强度，不提供作用符号。家族扩展、同源投射与实测位点应允许不同的不确定性。

已有 161 个细胞，先以主效应为主、少量二因子交互为扩展；三因子组由有效样本和可辨识性决定，默认不启用。不借用原仓库的 24/30/50 等门槛作为本数据已验证阈值，也不因结果弱而自动放宽。

若两个 RBP 几乎完全共变，输出 `individual_effect_unresolved`，保留模块/联合剂量结果，不把正则化任意选择的成员归因当作真实识别。

### 目标和支持

训练以带收缩的计数复合似然为主，按基因平衡相关事件的贡献，避免同一基因大量事件支配优化。重叠事件不增加独立样本数。拟合使用原细胞计数；软分箱只用于曲线展示或辅助诊断，不能把重叠平滑得到的 50 行当作 50 个独立重复。

拟合所有 161 个细胞，保留原始细胞/批次/阶段支持记录。平滑度和稀疏度先固定或做预先声明的 WT 内部稳定性敏感性分析，不接触外部 KO 标签选参。正式参数表需在实现前锁定，不能从参考仓库静默继承。

## 8. 虚拟扰动：冻结模型、改变输入、比较差分

对目标 r、失活比例 `q ∈ [0,1]`：

`E_ir_new = (1-q) · E_ir_WT`

`x_ir_new = log1p(E_ir_new)`

其余输入代理量、原始归一化分母、状态、窗口、模型参数和候选结构均保持冻结。不能直接用 `(1-q) · log1p(E)`，不能将剩余 RBP 重新归一化放大，也不能在每次 KO 后重新分配贡献权重。

```text
1. 在同一状态计算 WT logits：η_WT = F(x_WT, z_WT)。
2. 只改变指定目标的代理量；多目标时同时改变。
3. 重新求值：η_new = F(x_new, z_WT)。
4. 得到 Δη = η_new - η_WT。
5. 由同一基线求出合法分支概率与 Δp。
```

可以使用模型 WT 概率作为基线；若使用从 WT 计数收缩得到的参考组成，采用：

`p_new = softmax(log(p_WT_reference) + Δη)`

这样保留 WT 残差背景且保证概率和为 1。参考概率应来自正值收缩估计，不能给原始零比例随意加未经记录的数。`q=0` 的差分必须严格为零，联合敲除直接求值一次，不能把各单 KO 的 ΔPSI 相加。

干预 DDX5 而 RBFOX2 不变时，包含两者的条件交互项仍会变化；这提供了无 motif 因子影响事件的路径，无需假定 RBFOX2 表达随之改变。是否有协同由数据和约束决定，不预置正方向。

当前干预是表达代理量失活下的条件剪接响应。现实 KO 的蛋白消失时程、反馈、补偿和毒性未被该操作自动表示。

## 9. 支持、外推和路径解释

借鉴 CausalBridge 的组支持检查，但细化输出：

- `supported_conditional`：WT 条件变异和组合输入有支持。
- `weak_identifiability`：状态/批次/伙伴共线性使个体效应不稳定。
- `conditional_extrapolation`：剂量超出 WT 范围，允许作为敏感性情景报告，不包装成支持内预测。
- `no_event_anchor`：因子有 PPI，但没有可用事件锚点。
- `insufficient_event_counts`：有效分母不足。
- `structure_unresolved`：事件边际可预测，但无法唯一还原链/异构体组成。
- `unmodelled`：没有可执行模型；不以 Δ=0 替代。

组支持不足时只回退到真正拟合且适用的条件主效应模型；若主效应也不可识别，则报告不可用。不能因为 KO=0 在 WT 范围外就默认为无效应，也不能因样条输出有界而默认外推可靠。

输出保留目标、剂量、细胞状态、事件、Δ分支概率、观测分母、先验路径、模型参数版本、条件支持、外推标记和重采样区间。区间初期仅反映观测/拟合稳定性，不称为已校准的真实 KO 因果区间。若缺少胚胎/供体标识，细胞重采样也不能代表跨胚胎不确定性。

## 10. 事件到完整结构组成

为每个基因建立合法结构集合及两个映射：

- `H_ek`：结构 k 是否支持某事件分支；多分支时使用对应的分支维度。
- `D_ek`：结构 k 是否对该事件有完整可判定覆盖。

二分支事件的预测比例为：

`ψ_e(π) = Σ_k H_ek π_k / Σ_k D_ek π_k`

分母为零则事件不可判定。多分支同理，不能把未覆盖的截短链当作排除分支。

以 WT 结构组成为起点，在合法结构 simplex 上求解：

`π_new = argmin[KL(π || π_WT) + λ Σ_e w_e discrepancy(p_e(π), p_e_new)]`

权重反映计数支持和可辨识性；相关/重叠事件不能按独立证据无限放大。`λ` 是结构重建参数，需记录敏感性，不能按盲测 KO 调优。要求 π 非负、和为 1，并报告事件目标与合法结构之间无法消除的不一致。

这里只在实际观测且质量允许的结构上调整 usage。不补全可能缺失的 S，不生成未经支持的新转录本。若现有链不足以确定完整结构，L2 明确输出链级或可辨识结构集合；L1 结果仍可保留。

## 11. 一个与数据相关的示例

以下是机制示例，不是已计算的 KO 结果：

```text
事件 E：外显子 1—2—3，或外显子 1—3。
RBFOX2：事件附近存在自己的 motif/CLIP 候选。
DDX5：没有当前库的 motif，但有与相关复合体/伙伴的关系证据。

WT 拟合：在阶段、批次背景下，估计 RBFOX2、DDX5 与 E 的条件响应。
DDX5 KD：仅降低 DDX5 的表达代理量，保持 RBFOX2 和 WT 状态不变。
输出：E 的包含概率变化，以及支持 1—2—3 / 1—3 结构的 usage 变化。
解释：DDX5—伙伴/模块—事件的候选路径，而不是“DDX5 识别 RBFOX motif”。
```

若 DDX5 与 RBFOX2 在 WT 中完全共同变化，模型应报告无法单独区分两者，而不是为满足输出要求制造确定方向。

## 12. 首版实施顺序

1. 固定现有输入轴、归一化和观测语义；输出状态×因子×事件的数据支持、批次混杂和先验路径清单。
2. 先选有实际事件锚点且表达存在条件变异的少量 RBP，包括直接位点充分者及一例有依据的无 motif 伙伴；不凭 GO 覆盖率决定全部可执行目标。
3. 实现 gene-conditioned / stage-conditioned 的计数主效应模型，以及低自由度样条版本；所有细胞参与拟合。
4. 增加少量有 PPI/复合体依据的二因子条件交互，与主效应基线比较稳定性；不以训练 R² 改善单独宣称协同。
5. 实现剂量、联合扰动、严格 no-op、支持和路径输出；先完成 L1，再完成合法结构 L2。
6. 用锁定的外部 KO/KD 验证 L1/L2，区分严格 WT-only、扰动迁移和监督上限。外部 KO 不能用来挑特征、先验路径或超参数。
7. 通过预先规定的验证后，再考虑表达反馈与命运投影。

第一轮至少对照：零效应、只含状态/批次的无 RBP 模型、条件线性 RBP 模型、加入 motif/CLIP、再加入互作/复合体。L2 对照为事件边际独立预测和有长读长共现结构的重建。聚类指标不作为主要验收。

后续代码验收应覆盖：q=0 严格无变化、概率范围与总和、无分母不作为零、KO 不改其他输入归一化、联合扰动不重复累加、无可执行路径不返回生物学零效应、同一事件共享分子不膨胀独立样本数、家族/同源来源标签保留、mm10/mm39 逐块匹配以及模型保存重载一致。

## 13. 与现有 v0.1 方案的关系

保留 v0.1 的核心目标：WT-only、状态依赖 L1、长读长结构受限 L2、外部扰动盲测和逐层推进。v0.2 明确引入已整合的互作/复合体先验、单输入与协同的条件化、冻结输入差分、对观测计数和组成的约束，以及当前样本/批次条件下关闭默认伪时间传播。
