# CISBP-RNA 对 SpliceFate 的适用性核查（2026-11-15）

结论：足以启动经过筛选的 motif 先验层；单独不足以支持可信的 WT→KO 效应预测。WT 条件模型仍需限定外推范围，并用独立扰动检验。

## 数据与统计口径

从官方网站按物种下载 build 2.00 的 RBP Information 与 PFMs；保留 ZIP、下载 URL、SHA256 和逐矩阵 QC。统计按唯一 RBP_ID，D/I/N 使用数据库自身标签，分别表示直接测量、推断、无 motif；这些数字不是文献中全部实验支持因子的计数，也不是全部剪接因子的覆盖率。

小鼠状态为 D=7、I=202、N=215；人状态为 D=189、I=82、N=194。替代 motif 的可用性不等同于生物学等价性，不能不加记录地替换默认 motif。空或缺失文件属于本次下载包核查结果，不代表对应蛋白没有已知结合偏好。小鼠 Nova2 在该包的关联矩阵均不可用，可另从原论文或其他 motif 资源补充。

## 能力与缺口

- 可提供：因子 ID、物种、结合结构域、结合偏好矩阵、实验/推断来源、部分推断方法说明。配合参考基因组及事件坐标，可定位候选顺式元件。
- 尚不提供：目标细胞中实测占据位置、每条 RBP–event 边的促进/抑制方向、KO 剂量响应、蛋白有效活性、目标系统真实扰动效应或命运终点。
- 相同 motif 不能唯一归因：小鼠 Srsf4/Srsf6 默认共享 M00815_2.00；Tra2a/Tra2b 共享 M00826_2.00。需要结合位置、非扰动 CLIP、状态条件和独立验证；CLIP 结合本身仍不证明调控方向。
- 候选位置应在转录方向正确的 pre-mRNA 上扫描，包含事件相关外显子及内含子窗口；不能把序列命中当作真实占据或因果靶点。
- WT-only 制度可使用非扰动结合先验。由 KD 学得的 KATMAP 等有方向权重须归入独立迁移模式；盲测效应不得用于选边或调参。

## 开发判断

可以以 CISBP 为主要 motif 来源启动小规模先验和状态条件模型开发。接下来应对候选因子做表达变异/共线性检查、与事件序列和物种匹配 CLIP 求交，并锁定独立扰动验证。候选表达较充分的因子包括 Ptbp1、Rbfox2、Celf1、Esrp1、Srsf1/2/3；这里只按 motif 与表达给出候选，尚未按 CLIP、变异度或验证可得性完成排序。

本次没有进行事件序列扫描，不能报告靶事件覆盖率，也没有训练或模拟任何 KO。
