# SpliceFate 整合库覆盖度核查（2026-11-15）

结论：常见序列特异性调控因子的证据足以支持有限因子原型；对全部剪接相关蛋白的覆盖仍有限。尚未证明 WT→KO 效应预测能力。

## 统计范围

分母为当前整合库按 GO 标签 containing `splic` 整理的 408 个小鼠剪接相关候选，包含核心加工组分，非权威完整剪接因子全集。393 个与现有基因注释匹配，383 个在当前 161 个细胞中至少一次检出基因 UMI。

motif 仅计入通过矩阵 QC 的 CISBP/ATtRACT 序列偏好记录，排除仅有突变体证据及 ENCORI HOMER 富集候选；包含数据库标记为推断的 motif。CLIP 仅计同物种小鼠实验，但未要求组织和条件与当前系统一致，也未逐项完成 WT 条件审核。

| 证据 | 408 个候选中的数量 | 占比 |
|---|---:|---:|
| 可用序列偏好 motif | 101 | 24.8% |
| 小鼠 CLIP 实验 | 51 | 12.5% |
| 两者兼有 | 42 | 10.3% |
| 至少一项 | 110 | 27.0% |

## 当前剪接事件的区域覆盖

现有事件来自 `GSE250381_local_events_v8_20261108/groups.json`，共 1,950 个局部竞争事件、1,060 个基因。以原有公共锚点之间的完整事件跨度为区域（含内含子），未增加额外侧翼窗口。使用上述 51 个候选的 312 个 canonical 小鼠 CLIP 实验，共检查 2,510,379 条位点记录；要求 mm10 坐标及链方向一致。

- 有至少一个结合峰重叠的事件：1,529/1,950（78.4%）。
- 至少两个不同因子标记有重叠的事件：1,265。这些证据可能来自不同组织，不能视为本系统同细胞共占据。
- 至少一个事件区域有峰的基因：838/1,060（79.1%）。
- cassette：968/1164（83.2%）。
- shared_left：290/394（73.6%）。
- shared_right：271/392（69.1%）。

这是物理区域重叠，区域内含部分较长内含子；尚未评价距可变剪接边界的位置特异性，也未进行 motif 扫描、组织匹配或直接剪接调控验证。因此不能将该比例解释为已有明确调控因果关系的事件比例。

更宽松的基因层统计中，983/1060（92.7%）个事件所在基因有剪接相关候选的结合注释。这也说明应区分基因覆盖、事件区域覆盖及真正的调控边覆盖。
