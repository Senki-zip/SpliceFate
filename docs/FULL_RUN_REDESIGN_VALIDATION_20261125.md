## 验证结果

本地 111 项测试通过。覆盖观测细胞设计基、状态列去共线、OOB 评估行隔离、噪声自由度偏置、缓存恒等、串并行一致性、事件事务续跑、指纹拒绝、二进制／稀疏存储、平滑与零剂量、三项贡献、联合支持域、五类状态、三种汇总、部分 bootstrap 失败及 R 依赖检查。测试文件不纳入仓库。

真实验证使用全部 662 个 WT 细胞、前 20 个先验支持事件：

- 完成 5,080 条单关系学习；4,965 条拟合成功，115 条因观测细胞内输入无变异跳过。
- 970 条关系通过 OOB 门槛，63 条入选，13 个事件形成联合模型；其余 7 个没有合格输入。
- 单独审计全事件轴中 10 个超过 8 分支的事件，记录为 `too_many_branches_unmodeled`。
- 完成 11 个官方 KO × 3 剂量模拟和 11 份同坐标外部评测。每份汇总均覆盖全部 40,756 个条件／事件分支行。
- 这 20 个事件中，默认 11 个 KO 靶点均未入选，故这些场景变化为零；表内明确标注未入选或无先验路径，未拟合事件概率保留缺失。
- 补充对已入选 SF3B6 做 0.5 剂量实现检查，产生 1 个事件的非零响应，最大绝对分支概率变化 0.036549；写出 1,324 行事件、3,976 行剪接链结果。事件与链概率均归一化，三项贡献精确加和；同一靶点零剂量严格恒等。
- 实际在 3 个事件提交后发送中断，续跑识别 3 个已完成事件、只补算 17 个。最终单关系数值和排名与未中断结果完全一致。

最终完整验证耗时 192.63 秒，其中准备约 71 秒、20 事件拟合约 14 秒、33 场景模拟约 105 秒；`/usr/bin/time -v` 报告最大进程 RSS 约 5.17 GiB，该值不代表进程树合计内存。产物约 1.5 GiB，主要为全事件先验数据库；最终 20 事件模型数据库约 780 KiB，预测与支持数组约 288 KiB。
