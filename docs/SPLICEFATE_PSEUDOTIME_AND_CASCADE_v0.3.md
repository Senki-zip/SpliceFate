# SpliceFate v0.3：剪接辅助伪时间与多证据级联扰动

日期：2026-11-16。状态：修订设计，尚未实现或训练。

实施更新：核心 Python 包、CLI、条件响应、结构重建和受注释约束的级联已实现；独立合成测试与可选 scVelo API 检查见 [实现交付](IMPLEMENTATION_v0.3.md)。用户随后要求先不管当前数据集，后续开发不基于该数据做模型取舍或完整训练；本稿下文保留设计时的假设与计划。

进一步明确后的当前实现：时间校准主线是借鉴内含子/外显子数量关系、独立实现的 `intron_phase`，不是完整 scVelo 调用。成熟分支组成校准保留为 `composition` 比较及 `hybrid` 组合；两者输入和解释分开。独立计数模块使用每基因相位偏离和有向图辅助排序，不将内含子总量直接当作时间，也不宣称已经估计完整剪接动力学。

最新实现（优先于下文早期方案）：各上下文用完整基因计数计算官方 CytoTRACE 0.3.1 评分并选最高分起点，再运行 DPT 得到基础排序，再用有可靠 S 信息的局部约束做小幅校准；没有支持的细胞原值不动，不重建第二条完整轨迹。小簇共享/全局上下文仍用 DPT，替代原先 Palantir 回退。当前实现不以完整 velocity/latent-time 拟合作为必要步骤。

本稿按用户最新方向修订 v0.2：剪接参与 WT 伪时间校准，motif/CLIP 与蛋白互作/复合体共同参与级联。v0.2 中“初版同期模型、暂不启用传播”的安排由本稿替代。计数观测、组成约束、全细胞拟合及外部扰动验证等约定继续有效。

## 1. 总体流程

```text
WT G ──初始状态图──┐
                   ├─ 阶段/分支约束下的剪接辅助校准 → 固定 WT 轨迹
WT S ──覆盖度质控──┘                              │
                                                  ↓
RBP 剂量 → 蛋白伙伴/复合体功能响应 → RNA 位点 → 剪接事件 → 合法结构组成
   └──────────自身 motif/CLIP 路径───────┘                   │
                                                            ↓
                                下游 RBP 剪接组成更新 → 下一轮
```

轨迹只用 WT 建立，扰动中冻结。图中的蛋白互作表示可行机制关系，不自动变成有方向、有符号的调控箭头；实际传播方向由干预入口、RNA 锚点与可拟合的响应方程共同限定。

## 2. 剪接怎样辅助校准伪时间

### 2.0 聚类与建模上下文沿用 CausalBridge

按用户要求，参考聚类采用已核对的 CausalBridge 当前 `config.yaml` 选择，而不是另设聚类模型：

| 配置 | 采用值 |
|---|---|
| 方法 | G 表达参考 → PCA → KNN → Leiden |
| `cluster_key` | `leiden` |
| `n_neighbors` | 20 |
| `n_pcs` | 20，用于 KNN 图；PCA 本身沿用仓库至少计算 50 个可估计分量的逻辑 |
| `resolution` | 0.5，来自当前配置文件；函数缺省 0.8 不替代显式配置 |
| `random_state` | 42 |
| `min_cells_per_cluster` | 50 |
| `fallback_pseudotime_method` | `palantir` |
| PAGA 合并 | 默认关闭，沿用当前显式配置；启用时阈值 0.08、最少 lineage 细胞 50 |

如果输入已有经核验、与当前 WT 细胞和参考预处理一致的 `leiden` 标签，则复用；否则重新计算。固定参考聚类后按细胞 ID 传递给模型，不因候选 RBP、motif、先验数据库或 KO 目标不同反复改变聚类。模型与参考特征轴分别记录。

聚类仍使用 G；S 用于聚类/上下文确定后的伪时间校准，不在本次选择中改成 G+S 联合 Leiden。阶段标签用于方向检查、协变量和批次诊断，不直接替代 Leiden 标签。KNN 用于聚类和轨迹，不用于 S 填补或扰动特征借用。UMAP 只用于展示。

RNA 归一化和特征选择继续保持用户已确定的 CP100000/log1p、Seurat v3 3000 HVG，不复制 CausalBridge CP10k 或针对单次 KO 加基因改变参考聚类。没有 ATAC 输入，不执行其 ATAC QC 和跨模态细胞交集；现有 161 个细胞按原数据契约保留。该范围是聚类选择的沿用，不代表照搬完整预处理管线。

上下文选择：满足 50 细胞的簇可独立建模；若全部不足 50，则沿用 CausalBridge 的全局 Palantir 回退，再接受剪接辅助校准。PAGA 默认不为了扩大样本而自动打开。

CausalBridge 在“部分簇不足 50、另有大簇”时会跳过小簇。为延续本项目此前全细胞参与的约定，本项目只在这里作明确适配：小簇保留在全 WT 的共享条件拟合中，不独立拟合簇专属曲线，不因小样本删除细胞；受支持的大簇可有局部偏离。不同分支/不连通状态仍保留边界，不为凑样本强行连成一条伪时间。局部与共享预测对同一细胞择一使用并记录来源，不能叠加两次。若共享轨迹缺少支持，仍输出该状态的同期条件结果及轨迹不可用标签。

因此先输出实际 Leiden 大小、回退/共享方案和每个细胞的拟合上下文，再开始 S 校准与响应拟合；目前没有运行聚类，尚不能声称本数据将得到多少簇或是否触发回退。

### 2.1 表达建立初始框架，剪接提供补充约束

保留当前 Seurat v3 3000 HVG、CP100000/log1p；全量基因目录用于提取 RBP。先用 G 建立 WT 状态图和初始坐标 `t_G`，再用质量合格的剪接程序细化状态接近程度、局部排序和分支候选。

真实阶段是时间锚点，不能因一个噪声剪接信号随意倒转整体阶段顺序。同一阶段内部排序可以调整，分支附近可出现新的剪接支持，但需要同时报告表达与剪接的支持和冲突。ESC 单独处理，不强接为胚胎发育的后续时间点。

### 2.2 直接使用带分母的 S 信息

- 二分支事件使用 beta-binomial、多分支使用 Dirichlet–multinomial 的后验分支组成和不确定性。
- `N_ie=0` 保持缺失。不会借邻居补 S，不把无观测设为排除分支或 PSI=0。
- 细胞间 S 距离仅用共同可判定且有支持的事件；用分母和后验精度调节可靠性。缺少共同支持时不产生 S 相似证据，退回表达框架。
- 对共享分子的同基因事件分组或限权，防止一个高表达基因贡献大量相关事件而主导轨迹。
- 检查读长、事件分母、批次、阶段对 S 程序的影响；不让测序覆盖本身成为“发育轴”。

此处的细胞图用于状态排序，不用于补全缺失异构体，也不把相邻细胞的 S 写进目标细胞的观测矩阵。

### 2.3 可靠性自适应融合

在满足表达图局部几何和已知阶段方向的候选连接上，加入剪接相似性约束。一个可实施的边代价为：

`cost_ij = (1-w_ij) dG_ij + w_ij dS_ij`

`w_ij = λ_S · reliability_ij`，其中两种距离先按 WT 参考尺度归一化，`reliability_ij` 来自共同事件覆盖与稳定性，取值在 [0,1]。`λ_S` 是明确记录的融合参数，不预定未经验证的 0.5 权重。

该式是工程候选，不意味着距离线性混合已获生物学验证。初始版本比较 G-only 与可靠性加权 G+S，检查真实阶段一致性、跨批次稳定性、分支稳定性及重采样排序变化。若剪接没有稳定增量，允许 `λ_S=0`，不强迫它改变轨迹。

不以“RBP–event 拟合更好”或 KO 预测结果选择轨迹参数，也不将细胞图边解释为实际谱系追踪。没有真实时间间隔时，伪时间不是小时。

### 2.4 共享校准时间

全 WT 细胞用全部有支持的 S 特征计算一份校准时间。事件模型、bootstrap 与扰动模拟统一使用该时间，不按基因或目标事件分组排除特征，也不留出测试细胞。

拟合与模拟调用同一份已冻结的背景轨迹，不用模型 KO 输出反过来重排 WT。初期预测的是固定 WT 状态下的条件响应；真正状态迁移单独作为后续输出。

## 3. motif 与 PPI 如何共同构成级联

### 3.1 分开三个层次

| 层次 | 例子 | 计算角色 |
|---|---|---|
| 物理关系 | DDX5 与某伙伴存在互作；多个因子属于同复合体 | 限定可考虑的蛋白/模块路径，保留关系类型 |
| RNA 锚点 | 某伙伴在事件附近有 motif/CLIP | 将模块关联到具体 RNA 区域与事件，保留位置和链 |
| 响应函数 | 在固定 WT 状态下，模块成员剂量如何影响分支选择 | 决定数值变化和方向；不能仅从无向 PPI 得出 |

候选路径允许两类：

`r → 自身 motif/CLIP 位点 → e`

`r → 与 s 的功能组合/复合体 → s 的 motif/CLIP 位点 → e`

同复合体使用多成员关系表示，不展开成全部成员两两直接接触。家族共享、PPI 转移、直接物理和未指定关联的标签保留。不存在任何成员级 RNA 锚点的模块，不能仅靠 PPI 网络获得具体事件靶点。

### 3.2 模块响应进入事件预测器

采用 v0.2 的计数观测模型，调整预测器的组织方式：

`η_iek = b_ek(z_i,t_i) + Σ_r f_rek(x_ir,z_i,t_i) + Σ_c Q_cek(X_ic,z_i,t_i)`

`c` 是有来源的伙伴组合或复合体，`X_ic` 为其成员表达代理量。`Q_cek` 是其对事件分支 logit 的条件贡献，不命名为已经测量的蛋白活性或占据概率。

低数据量时，`Q` 可由少量成员主效应和中心化双因子交互表示；该模块中已计入的主效应不得在 `f` 中再次累加。主效应/交互同时拟合，约束和自由度明确保存。共享模块不必假定对不同事件具有相同效应方向。

这样，r 剂量降低可以改变 `Q(X_r,X_s)`，即使 s 的 RNA 表达没有改变。它表示伙伴组合的功能响应，不自动意味着 s 蛋白减少或失活。

不默认用成员最小值、乘积、PPI 分数或简单平均定义所有复合体活性；不同模块可能有促进、竞争或冗余。没有条件变异支持时，仅保留模块层联合扰动，个体归因标为不可区分。

### 3.3 由 WT 学习的组成级联

RBP 总表达与其自身有公共锚点的局部异构体组成共同作为输入。少数计数有支持的状态通过表达加权的 K−1 分支对比表示，各下游事件的响应系数从 WT 计数拟合，不提供人工 0–1 蛋白功能权重。

第一轮预测 RBP 自身的事件变化后，将相对 WT 的分支 log 概率变化作用到该 RBP 的实际观测组成，更新输入后执行下一轮。缺少组成观测的细胞不补值；无法拟合组成项的关系继续保留总表达响应。已有蛋白／domain 库仅用于附加结果解释，不参与传播门槛。

同步更新与冻结 WT 基线规则保留。完整配置、公式和输出见 README 的“WT 学习的异构体组成与多轮传播”。

## 4. 伪时间在传播中的用途

校准后的 WT 轨迹用于定义作用状态、共享系数的平滑与分支约束，也可提供沿轨迹变化的候选顺序证据。

第一版每个状态都可计算剂量响应，不要求人为等待一个 bin 才允许剪接改变。若后续启用 lag：

- 只沿同一支持分支读取允许的先前状态，真实阶段检查方向。
- 同期模型是必要基线，不能预设所有蛋白互作或剪接响应都需要一个 bin 的延迟。
- lag 选择与稳定性分析以真实细胞/样本为单位，考虑分箱重叠相关性；不把平滑后的行数当作独立样本。
- 不将“第一个显著 lag”直接命名为真实加工延迟，不用伪时间恢复分子内含子剪切顺序。

## 5. 多轮传播的数值规则

目标 r 的剂量先在非 log 单位上改变，再转换到模型输入；直接靶点在全部轮次保持干预约束。模型、轨迹、图、归一化分母均冻结。

每轮使用上一轮完整快照同步计算，避免遍历节点顺序改变结果。对任一有定义的状态层 v：

`delta_v^(d+1) = F_v(parent_WT + delta_parent^d, z_WT) - F_v(parent_WT, z_WT)`

`state_v^(d+1) = WT_reference_v + delta_v^(d+1)`

概率层在 logit 空间更新后 softmax；结构组成层在合法 simplex 上重建。每轮都相对 WT 重新求值，不能不断向上一轮结果重复加同一效应。某路径无新增输入变化时不重复累积。

PPI 无向环不自动成为可执行反馈环；必须先为状态转换定义函数。展开轮数是计算传播深度，不是实际时间。达到深度预算、输入超出支持、变化不再增加或出现不稳定时按状态记录停止原因；不把截断说成生物学收敛。

多路径解释用统一模型的总差分，直接/模块/间接分量通过预先定义的消融或顺序平均分解得到；不能将所有路径贡献独立相加而重复计算共享节点。多目标 KO 同时求值，保留协同非加性。

## 6. 示例

以下是待模型检验的路径示意，不是已经确认的本数据结果：

```text
DDX5 剂量降低
    ↓ 互作/复合体与条件响应
DDX5–RBFOX/LASR 相关模块的剪接贡献改变
    ↓ 伙伴 motif/CLIP 提供事件定位
事件 E 的分支选择改变
    ↓ 已观测长读长共现结构
合法链/异构体使用比例改变
    ↓ 下游 RBP R 的观测剪接组成改变，并有 WT 学习的组成响应
R 的组成输入更新，相关事件进一步改变
```

第一段不要求 RBFOX RNA 下降；最后一段通过 WT 学习的组成响应传播。相同剂量在不同 WT 伪时间位置可以得到不同的条件效应。

## 7. 实现与验收修订

实施顺序改为：

1. 按 CausalBridge 配置建立或核验 G-only Leiden 参考聚类，确定独立/共享/全局回退上下文，再构建 WT 轨迹和计数/覆盖诊断。
2. 加入剪接可靠性与局部校准，形成所有事件共享的冻结 G+S 背景轨迹；不新增测试细胞。
3. 从主库构建 motif/CLIP–事件锚点与蛋白伙伴/复合体路径，检查坐标与来源。
4. 拟合条件主效应和模块响应，完成直接/伙伴模式的 KO/KD 与合法结构重建。
5. 按计数支持建立 RBP 自身剪接状态与 WT 学习的下游组成响应，执行同步多轮级联。
6. 在外部保留扰动中比较增益，未达到 L1/L2 门槛不扩展为命运概率。

必要消融：G-only / G+S 校准；无 PPI / 加 PPI；去掉模块交互；保持度分布的 PPI 打乱；motif 相对位置打乱；单层 / 受限级联。数据中原 32-cell、blastocyst、ESC 的阶段–批次混杂单独标记，加入 S 不能消除此问题。

验收增加：所有事件使用同一份校准时间；q=0 全层严格不变；不可用 S 不影响缺失观测矩阵；PPI 不能凭空降低伙伴 RNA；无响应方程的边不执行；同步更新与节点顺序无关；共享节点不重复累积；概率/结构合法；传播深度和停止原因可追溯。

本轮只修订模型方案，没有修改主库、原始数据、既有归一化或启动训练。具体融合权重、样条自由度、正则化与传播预算仍需在实现配置中明确记录，不能从参考仓库自动继承。
